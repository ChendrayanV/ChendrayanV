## 🚀 Current Project: [Azure.Admin.Console](https://github.com/ChendrayanV/Azure.Admin.Console)

[![CI](https://github.com/ChendrayanV/Azure.Admin.Console/actions/workflows/ci.yml/badge.svg)](https://github.com/ChendrayanV/Azure.Admin.Console/actions/workflows/ci.yml)
[![PowerShell Gallery](https://img.shields.io/powershellgallery/v/Azure.Admin.Console?label=PowerShell%20Gallery)](https://www.powershellgallery.com/packages/Azure.Admin.Console)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/ChendrayanV/Azure.Admin.Console/blob/main/LICENSE)

An open-source PowerShell module, published on the PowerShell Gallery, for Azure administration reports and checks over plain REST, with no Az or Microsoft.Graph modules and no app registration.

- Tenant inventory, Azure Advisor, Defender for Cloud and Azure Policy compliance
- Azure Firewall rule search, NSG and virtual network assessments
- Cost reporting, cost anomalies and unused-resource detection
- Access reviews, attack paths and orphaned identities
- PSRule for Azure (Well-Architected rules) against the live estate
- Output as console views, PowerShell objects, CSV, PDF or interactive HTML reports

```powershell
Install-Module -Name Azure.Admin.Console -Scope CurrentUser
Connect-AAC
Show-AACDashboard
```
